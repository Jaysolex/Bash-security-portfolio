# System Resource Monitor Script

## Purpose
Identifies processes consuming excessive CPU or memory resources.

## Blue Team Use Case
Used by blue team analysts to detect potential malware, cryptominers, or abused processes.

## Detection Logic
- Lists top CPU-consuming processes
- Lists top memory-consuming processes
