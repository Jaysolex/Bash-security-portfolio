# Basic Reconnaissance Script

## Purpose
Performs basic, non-intrusive reconnaissance against a target domain.

## Ethical Use Case
Used to gather publicly available information during the initial reconnaissance phase of a security assessment.

## Recon Techniques
- DNS record lookup
- HTTP header inspection

## Ethical Considerations
This script performs read-only, non-intrusive actions and does not attempt exploitation.
